------
Today, I'd like to build a small project that performs sentiment analysis on YouTube comments using DistilBERT. As a bonus, I also implemented a comment raffle feature commonly used by YouTubers.

------

File Structure
```
[Folder] yt_sentiment_project
-main.py
-sentiment_train.py
-sentiment_test.py
```

------

Libraries : 
```
selenium → for web crawling (collecting YouTube comments)
transformers → for running the DistilBERT sentiment analysis model
tqdm → for displaying progress bars during inference
datasets → for loading the IMDB movie review dataset used to train the model
```

------

How to Start ?
Step 1 :
```
sentiment_train.py
```

Step 2 :
```
main.py
```
